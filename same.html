Alignment: positions at which all three engines agree

Positions at which all three engines emit a label and, once spelling is normalised, write the same one. Selecting a row opens the corresponding bar of the score; closing it returns you to the same place in the list.

Agreement is not treated as proof of correctness. Every cell here carries the same locked textbook grade as on Disagreements, so three engines can agree and still be wrong together. The grading criterion is set out on Ratings.

Preliminary results. These are first results. After detailed validation, the final accuracy figures may change by up to ±5 percentage points for AnalysisGNN and AugmentedNet and by about ±1 point for musWM. See Ratings for how the margin was estimated.
