# musWM · Roman numeral validation

Public results site: three Roman-numeral analysers (musWM, AnalysisGNN, AugmentedNet) on the 335 scores of the When in Rome corpus, graded against Kostka, Payne & Almén, *Tonal Harmony*.

This repository contains the static website only: labels, scores and the interface. It contains no analysis-engine code. Results are preliminary.
